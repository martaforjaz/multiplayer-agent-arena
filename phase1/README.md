# Phase 1: coursework prototype

The first submission implemented the local arena, ship controls, obstacles, mines, collectible supplies, and a sensor-driven bot using Pygame and Pymunk. Run it with the dependencies declared at the root:

```bash
python -m pip install -r requirements.txt
python phase1/main.py
```

The Phase 2 HTTP multiplayer server lives at the repository root. The Phase 1 prototype uses an in-process bot controller. The original prototype source is preserved here with two changes to the asset paths so the launcher also works from the repository root. The menu background is resized for distribution.
